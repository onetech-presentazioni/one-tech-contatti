## Come lavorare insieme

La lista è pubblica e si legge senza account. Per registrare un contatto o completare un post, premi il pulsante nella scheda: si apre una segnalazione già compilata su GitHub. Accedi con il tuo account e premi **Create / Submit new issue** per confermare. Non modificare il blocco tecnico in fondo.

Torna alla lista dopo circa 1–2 minuti e premi **Aggiorna**. Anche gli altri vedranno lo stato, il tuo nome utente GitHub e l'orario. Premi di nuovo per annullare una conferma. **Nota condivisa** e **Aggiungi persona o post** seguono lo stesso percorso. Le nuove schede si trovano in **Aggiunte del team** e possono essere modificate.

Chiunque abbia un account GitHub può registrare aggiornamenti. Lista, note e registro sono pubblici: non inserire dati riservati. Non sono necessari token personali, password condivise, servizi di hosting esterni o inviti.

## Dati e funzionamento

I file originali sono conservati nel repository. Gli aggiornamenti sono registrati nelle Issues. GitHub Actions ricostruisce il registro dai messaggi validi in ordine di numero e pubblica la pagina con GitHub Pages; vengono preservati anche gli aggiornamenti arrivati durante una pubblicazione precedente. Il registro completo è consultabile nella scheda Issues.

Le vecchie spunte salvate solo nel browser del file locale non sono trasferite automaticamente. Il nuovo registro condiviso parte vuoto.
